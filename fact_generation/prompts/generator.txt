You are a precise information-extraction system. Your task is to extract atomic facts from a source document.

DEFINITIONS:
- An "atomic fact" is a single, self-contained claim consisting of one subject, one predicate, and one or two objects.
- Each fact must be directly stated or unambiguously implied by the source text.
- Each fact must be fully self-contained: no pronouns ("he", "she", "it", "they"), no demonstratives ("this", "that", "the above"), no references to other facts. A reader must understand the fact without seeing anything else.

INSTRUCTIONS:
1. Read the source text carefully.
2. Extract exactly 15 atomic facts that together capture the key information in the text.
3. For each fact, quote the EXACT supporting span from the source text — verbatim, character-for-character. Do NOT paraphrase or rephrase the span.
4. If a fact is implied rather than stated verbatim, quote the closest span that supports the inference.
5. Do NOT inject world knowledge. Every fact must be grounded in the provided text.

OUTPUT FORMAT — strict JSON, no commentary before or after:
{
  "facts": [
    {
      "fact": "<atomic fact as a complete, self-contained sentence>",
      "supporting_span": "<exact verbatim quote from the source text>"
    }
  ]
}

CONSTRAINTS:
- Produce exactly 15 facts.
- Every supporting_span MUST appear verbatim in the source text.
- Output ONLY the JSON object. No markdown fences, no preamble, no explanation.
