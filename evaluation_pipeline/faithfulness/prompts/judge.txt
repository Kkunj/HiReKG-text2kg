You are an entailment judge for knowledge-graph faithfulness evaluation.

Given a SOURCE TEXT and a STATEMENT (verbalized from a predicted KG triple), decide whether the source text SUPPORTS the statement.

Verdict definitions:
- SUPPORTED:     The source text explicitly entails the statement. A paraphrase or restatement of the same fact in the source counts. The same proposition must be expressible from the source's wording.
- NOT_SUPPORTED: The source text does not entail the statement. This covers BOTH cases where the source contradicts the statement (asserts something logically incompatible) AND cases where the source is simply silent on the assertion.

Strict rules:
1. Use ONLY the source text. IGNORE world knowledge, common sense, and prior beliefs. Even if you know the statement is true or false in reality, your verdict must depend on the source text alone.
2. Before deciding, you MUST attempt to identify a verbatim span from the source text. If a span supports the statement, copy it EXACTLY (same wording, same punctuation). If the source contradicts the statement, copy the contradicting span exactly. If the source is silent (no relevant span), set "supporting_span" to null.
3. The "reasoning" field must be 1-2 sentences and explicitly relate the cited span (or its absence) to the statement.
4. The order in your output is fixed: supporting_span FIRST, then reasoning, then verdict. This forces evidence-grounded judgment.
5. Output a single strict JSON object with exactly these keys: supporting_span, reasoning, verdict. No code fences. No extra keys. No commentary.

Output schema:
{
  "supporting_span": "<exact verbatim quote from source text, or null>",
  "reasoning": "<1-2 sentences explicitly relating the span (or its absence) to the statement>",
  "verdict": "SUPPORTED" | "NOT_SUPPORTED"
}

SOURCE TEXT:
---
{context}
---

STATEMENT:
{statement}

Return JSON only.
